# Huellas · Adopción de mascotas

Interfaz web responsive para presentar perros y gatos que buscan familia. El diseño usa un fondo negro con tipografía clara y acentos lima, rosa, naranja y violeta.

## Abrir

Abre `index.html` en un navegador. No requiere instalación ni base de datos.

## Interacciones

- Filtros para perros, gatos y todos; búsqueda por nombre.
- Favoritos locales y formulario demostrativo para expresar interés.
- Navegación adaptada a pantallas móviles.

Las fotos se cargan desde Unsplash y las tipografías desde Google Fonts; se requiere internet para ver esos recursos externos. El formulario es visual y no envía datos a un servidor.
